O **Titan Framework** foi desenvolvido no Laboratório de Engenharia de Software da UFMS para instanciar rapidamente sistemas gerenciadores de conteúdo e aplicações web a partir de descrições declarativas, dentro de uma abordagem de linha de produtos de software. Serviu de base ao Titan Architect, aos portais institucionais da UFMS e a diversos sistemas de gestão de fomento.

**Meu papel:** criador e mantenedor principal, do LEDES (2005) até 2022.

**Registros no INPI:** versões 1.0 e 2.0 (2014) e 3.0 (2015).
